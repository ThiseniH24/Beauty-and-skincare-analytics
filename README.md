# Beauty & Skincare Analytics 💄

> Does price actually mean better skincare? This project explores 8,000+ cosmetic products and 1M+ customer reviews through data analysis, NLP, and machine learning.

## 🔍 Project Overview
This end-to-end data science project investigates what actually drives skincare 
product quality — ingredients, price, brand, or something else entirely.

| Phase | Description | Status |
|-------|-------------|--------|
| EDA & Visualisation | Ingredient trends, price vs rating, brand analysis | ✅ Done (Tableau) |
| Python EDA | Reproducing and extending findings in Python | 🚧 In progress |
| Sentiment Analysis | NLP classifier on customer reviews | 🔜 Coming soon |
| Recommender System | Content-based product recommendations | 🔜 Coming soon |
| Streamlit App | Interactive web app deployment | 🔜 Coming soon |
